C Programming - Arrays

Learn how to store multiple values using arrays

← Back to Notes

1. What is an Array?

An array is a collection of elements of the same data type stored under a single variable name.

Each element of an array is accessed using an index. In C, array indexing starts from 0.

Syntax:

data_type array_name[size];

Example:

int marks[5];

2. Initializing an Array

We can initialize an array while declaring it.

Example:

int marks[5] = {80, 75, 90, 85, 70};

Here, the array contains five integer values.

3. Accessing Array Elements

Array elements are accessed using their index number. 

#include <stdio.h>

int main()
{
    int marks[5] = {80, 75, 90, 85, 70};

    printf("%d\n", marks[0]);
    printf("%d\n", marks[1]);
    printf("%d\n", marks[2]);

    return 0;
}

Output:

80
75
90

4. Taking Array Input

We can use a loop and scanf() to take values from the user. 

#include <stdio.h>

int main()
{
    int a[5];

    for(int i = 0; i < 5; i++)
    {
        printf("Enter element %d: ", i + 1);
        scanf("%d", &a[i]);
    }

    printf("Array elements are:\n");

    for(int i = 0; i < 5; i++)
    {
        printf("%d ", a[i]);
    }

    return 0;
}

5. One-Dimensional Array

A one-dimensional array stores elements in a single row. 

int numbers[5] = {10, 20, 30, 40, 50};

Indexes:

Index:    0   1   2   3   4
Value:   10  20  30  40  50

6. Two-Dimensional Array

A two-dimensional array stores data in rows and columns. It is commonly used to represent matrices.

Example:

int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

Output:

1 2 3
4 5 6

7. Finding Sum of Array Elements

#include <stdio.h>

int main()
{
    int a[5] = {10, 20, 30, 40, 50};
    int sum = 0;

    for(int i = 0; i < 5; i++)
    {
        sum = sum + a[i];
    }

    printf("Sum = %d", sum);

    return 0;
}

Output:

Sum = 150

8. Important Points to Remember

  • Array stores multiple values of the same data type.
  • Array indexing starts from 0.
  • The last index is always size - 1.
  • Loops are commonly used to process arrays.
  • Arrays can be one-dimensional or multi-dimensional.
