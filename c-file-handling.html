C Programming - File Handling

Learn how to create, open, read and write files in C

← Back to Notes

1. What is File Handling?

File handling in C is used to store data permanently in a file. It allows us to create, open, read, write and close files.

File handling is useful when we want data to remain saved even after the program finishes.

2. File Pointer

A file pointer is used to access and work with a file. It is declared using the FILE data type. 

FILE *fp;

Here, fp is a file pointer.

3. Opening a File

The fopen() function is used to open a file.

Syntax:

FILE *fp;
fp = fopen("filename", "mode");

4. File Opening Modes

  • r - Opens a file for reading.
  • w - Opens a file for writing.
  • a - Opens a file for appending data.
  • r+ - Opens a file for reading and writing.
  • w+ - Opens a file for reading and writing and creates/truncates the file.
  • a+ - Opens a file for reading and appending.

5. Writing to a File

The fprintf() function can be used to write formatted data into a file. 

#include <stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("data.txt", "w");

    fprintf(fp, "Hello C Programming!");

    fclose(fp);

    return 0;
}

This program creates or overwrites data.txt and writes the given message into it.

6. Reading from a File

The fscanf() function can be used to read formatted data from a file. 

#include <stdio.h>

int main()
{
    FILE *fp;
    char text[50];

    fp = fopen("data.txt", "r");

    fscanf(fp, "%49s", text);

    printf("%s", text);

    fclose(fp);

    return 0;
}

7. Closing a File

The fclose() function is used to close an opened file. 

fclose(fp);

It is good practice to close a file after completing the required operations.

8. Checking if File Opened Successfully

We should check whether the file was opened successfully. If fopen() fails, it returns NULL. 

#include <stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("data.txt", "r");

    if (fp == NULL)
    {
        printf("File could not be opened.");
    }
    else
    {
        printf("File opened successfully.");
        fclose(fp);
    }

    return 0;
}

9. Common File Handling Functions

  • fopen() - Opens a file.
  • fclose() - Closes a file.
  • fprintf() - Writes formatted data to a file.
  • fscanf() - Reads formatted data from a file.
  • fgetc() - Reads one character from a file.
  • fputc() - Writes one character to a file.
  • fgets() - Reads a line/string from a file.
  • fputs() - Writes a string to a file.

10. Important Points

  • Include stdio.h for file handling functions.
  • Use FILE * to declare a file pointer.
  • Use fopen() to open a file.
  • Always check if the file opened successfully.
  • Use fclose() after completing file operations.
  • Different modes are used for reading, writing and appending.
