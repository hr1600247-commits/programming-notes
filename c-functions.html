C Programming - Functions

Learn how to create reusable blocks of code

← Back to Notes

1. What is a Function?

A function is a block of code that performs a specific task. Functions make programs easier to understand, reuse and maintain.

Basic Syntax:

return_type function_name(parameters)
{
    // statements
}

2. Types of Functions

  • Library Functions - already provided by C libraries.
  • User-Defined Functions - created by the programmer.

Examples of Library Functions:

printf()
scanf()
strlen()
sqrt()

3. Function Declaration

A function declaration tells the compiler about the function before it is used. 

int add(int, int);

4. Function Definition

The function definition contains the actual statements that perform the task. 

int add(int a, int b)
{
    return a + b;
}

5. Function Call

A function call is used to execute a function. 

result = add(10, 20);

6. Simple Function Example

#include <stdio.h>

void greet()
{
    printf("Hello, C Programming!");
}

int main()
{
    greet();

    return 0;
}

Output:

Hello, C Programming!

7. Function with Parameters

Parameters allow us to pass values to a function. 

#include <stdio.h>

void greet(char name[])
{
    printf("Hello %s", name);
}

int main()
{
    greet("Harsh");

    return 0;
}

Output:

Hello Harsh

8. Function with Return Value

A function can return a value using the return statement. 

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main()
{
    int result;

    result = add(10, 20);

    printf("Sum = %d", result);

    return 0;
}

Output:

Sum = 30

9. Function with No Parameter and No Return Value

#include <stdio.h>

void display()
{
    printf("Welcome to C Programming");
}

int main()
{
    display();

    return 0;
}

10. Function with Parameters and Return Value

#include <stdio.h>

int multiply(int a, int b)
{
    return a * b;
}

int main()
{
    int result = multiply(5, 4);

    printf("Product = %d", result);

    return 0;
}

Output:

Product = 20

11. Advantages of Functions

  • Code can be reused.
  • Programs become easier to understand.
  • Large programs can be divided into smaller parts.
  • Debugging becomes easier.
  • Code maintenance becomes easier.

Quick Revision

  • Declaration → tells the compiler about the function.
  • Definition → contains the function's code.
  • Call → executes the function.
  • Parameter → value received by the function.
  • Return → sends a value back from the function.
