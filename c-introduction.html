C Programming Notes

What is C?

C is a general-purpose, procedural programming language developed to write efficient and structured programs.

Features of C

  • Simple and efficient
  • Structured programming language
  • Portable
  • Fast execution
  • Supports functions
  • Supports pointers

First C Program


#include <stdio.h>

int main()
{
    printf("Hello World");

    return 0;
}

Output


Hello World

Important Points

  • #include <stdio.h> is used for input/output functions.
  • main() is the starting point of a C program.
  • printf() is used to display output.
  • return 0; indicates successful program execution.
