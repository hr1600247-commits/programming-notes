Learn how to repeat statements using loops

1. What are Loops?

Loops are used in C programming to repeatedly execute a block of statements as long as a given condition is true.

There are three main types of loops in C:

  • for loop
  • while loop
  • do-while loop

2. For Loop

A for loop is generally used when we know how many times we want to repeat a block of code.

Syntax:

for(initialization; condition; increment/decrement)
{
    // statements
}

Example:

#include <stdio.h>

int main()
{
    for(int i = 1; i <= 5; i++)
    {
        printf("%d\n", i);
    }

    return 0;
}

Output:

1
2
3
4
5

3. While Loop

A while loop executes a block of code repeatedly as long as the condition is true.

Syntax:

while(condition)
{
    // statements
}

Example:

#include <stdio.h>

int main()
{
    int i = 1;

    while(i <= 5)
    {
        printf("%d\n", i);
        i++;
    }

    return 0;
}

Output:

1
2
3
4
5

4. Do-While Loop

A do-while loop executes the statements at least once before checking the condition.

Syntax:

do
{
    // statements
}
while(condition);

Example:

#include <stdio.h>

int main()
{
    int i = 1;

    do
    {
        printf("%d\n", i);
        i++;
    }
    while(i <= 5);

    return 0;
}

Output:

1
2
3
4
5

5. Break Statement

The break statement is used to immediately stop a loop.

Example:

#include <stdio.h>

int main()
{
    for(int i = 1; i <= 5; i++)
    {
        if(i == 3)
        {
            break;
        }

        printf("%d\n", i);
    }

    return 0;
}

Output:

1
2

6. Continue Statement

The continue statement skips the current iteration and moves to the next iteration of the loop.

Example:

#include <stdio.h>

int main()
{
    for(int i = 1; i <= 5; i++)
    {
        if(i == 3)
        {
            continue;
        }

        printf("%d\n", i);
    }

    return 0;
}

Output:

1
2
4
5

7. Quick Revision

  • for → Used when the number of iterations is known.
  • while → Condition is checked before execution.
  • do-while → Executes at least once.
  • break → Stops the loop.
  • continue → Skips the current iteration.
