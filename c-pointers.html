C Programming - Pointers

Understand memory addresses and pointers

1. What is a Pointer?

A pointer is a variable that stores the memory address of another variable.

Syntax:

data_type *pointer_name;

Example:

int *ptr;

2. Address-of Operator (&)

The & operator is called the address-of operator. It gives the memory address of a variable. 

#include <stdio.h>

int main()
{
    int x = 10;

    printf("Value = %d\n", x);
    printf("Address = %p", (void*)&x);

    return 0;
}

3. Dereference Operator (*)

The * operator is used to access the value stored at the address held by a pointer. 

#include <stdio.h>

int main()
{
    int x = 10;
    int *ptr = &x;

    printf("Value of x = %d\n", x);
    printf("Value using pointer = %d", *ptr);

    return 0;
}

Output:

Value of x = 10
Value using pointer = 10

4. Pointer Example

#include <stdio.h>

int main()
{
    int number = 25;
    int *ptr;

    ptr = &number;

    printf("Number = %d\n", number);
    printf("Address = %p\n", (void*)ptr);
    printf("Value using pointer = %d\n", *ptr);

    return 0;
}

5. Changing a Value Using Pointer

A pointer can be used to change the value of the variable whose address it stores. 

#include <stdio.h>

int main()
{
    int x = 10;
    int *ptr = &x;

    *ptr = 50;

    printf("x = %d", x);

    return 0;
}

Output:

x = 50

6. Pointer and Arrays

The name of an array represents the address of its first element in many expressions. 

#include <stdio.h>

int main()
{
    int a[3] = {10, 20, 30};
    int *ptr = a;

    printf("%d\n", *ptr);
    printf("%d\n", *(ptr + 1));
    printf("%d\n", *(ptr + 2));

    return 0;
}

Output:

10
20
30

7. Pointers and Functions

Pointers can be passed to functions so that the function can modify the original variables. 

#include <stdio.h>

void change(int *x)
{
    *x = 100;
}

int main()
{
    int number = 10;

    change(&number);

    printf("Number = %d", number);

    return 0;
}

Output:

Number = 100

8. NULL Pointer

A NULL pointer does not point to a valid memory location. It is commonly used when a pointer does not currently have a valid address. 

#include <stdio.h>

int main()
{
    int *ptr = NULL;

    if(ptr == NULL)
    {
        printf("Pointer is NULL");
    }

    return 0;
}

Output:

Pointer is NULL

9. Important Pointer Terms

  • Pointer → stores an address.
  • & → gets the address of a variable.
  • * → accesses the value at an address.
  • NULL → represents a pointer with no valid target.

10. Quick Revision

int x = 10;
int *ptr = &x;

Here:

  • x stores the value 10.
  • &x gives the address of x.
  • ptr stores the address of x.
  • *ptr gives the value stored in x.
