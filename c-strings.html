1. What is a String?

A string is a sequence of characters stored in a character array. In C, every string ends with a special null character \0.

Example:

char name[] = "Harsh";

Internally, it is stored as: 

H   a   r   s   h   \0

2. Declaring a String

A string can be declared using a character array.

char name[20];

We can also initialize it while declaring:

char name[] = "Harsh";

3. Taking String Input

The scanf() function can be used to take a single-word string as input. 

#include <stdio.h>

int main()
{
    char name[50];

    printf("Enter your name: ");
    scanf("%49s", name);

    printf("Hello %s", name);

    return 0;
}

Example Output:

Enter your name: Harsh
Hello Harsh

4. Reading a Full Line

fgets() can be used when the input may contain spaces. 

#include <stdio.h>

int main()
{
    char name[50];

    printf("Enter your full name: ");
    fgets(name, sizeof(name), stdin);

    printf("Your name is: %s", name);

    return 0;
}

5. String Functions

C provides several useful string functions through the string.h header file.

  • strlen() - finds the length of a string
  • strcpy() - copies one string into another
  • strcat() - joins two strings
  • strcmp() - compares two strings

6. strlen()

The strlen() function returns the number of characters in a string, excluding \0. 

#include <stdio.h>
#include <string.h>

int main()
{
    char name[] = "Harsh";

    printf("Length = %zu", strlen(name));

    return 0;
}

Output:

Length = 5

7. strcpy()

The strcpy() function copies one string into another. 

#include <stdio.h>
#include <string.h>

int main()
{
    char source[] = "Hello";
    char destination[20];

    strcpy(destination, source);

    printf("%s", destination);

    return 0;
}

Output:

Hello

8. strcat()

The strcat() function joins two strings together. 

#include <stdio.h>
#include <string.h>

int main()
{
    char first[30] = "Hello ";
    char second[] = "World";

    strcat(first, second);

    printf("%s", first);

    return 0;
}

Output:

Hello World

9. strcmp()

The strcmp() function compares two strings. 

#include <stdio.h>
#include <string.h>

int main()
{
    char a[] = "apple";
    char b[] = "apple";

    if(strcmp(a, b) == 0)
    {
        printf("Strings are equal");
    }
    else
    {
        printf("Strings are not equal");
    }

    return 0;
}

Output:

Strings are equal

10. Important Points

  • Strings are stored using character arrays.
  • Every C string ends with \0.
  • string.h contains common string functions.
  • strlen() finds string length.
  • strcpy() copies strings.
  • strcat() joins strings.
  • strcmp() compares strings.
