C Programming - Structures & Unions

Learn how to group different types of data

← Back to Notes

1. What is a Structure?

A structure is a user-defined data type in C that allows us to group variables of different data types under one name.

Syntax:

struct StructureName
{
    data_type member1;
    data_type member2;
    data_type member3;
};

2. Structure Example

#include <stdio.h>

struct Student
{
    int roll;
    char grade;
    float marks;
};

int main()
{
    struct Student s1;

    s1.roll = 101;
    s1.grade = 'A';
    s1.marks = 89.5;

    printf("Roll = %d\n", s1.roll);
    printf("Grade = %c\n", s1.grade);
    printf("Marks = %.2f\n", s1.marks);

    return 0;
}

Output:

Roll = 101
Grade = A
Marks = 89.50

3. Structure Initialization

A structure can also be initialized while declaring its variable. 

struct Student
{
    int roll;
    char grade;
    float marks;
};

struct Student s1 = {101, 'A', 89.5};

4. Accessing Structure Members

The dot . operator is used to access members of a structure. 

s1.roll
s1.grade
s1.marks

5. Array of Structures

We can create an array of structures to store information about multiple objects. 

#include <stdio.h>

struct Student
{
    int roll;
    float marks;
};

int main()
{
    struct Student s[2];

    s[0].roll = 101;
    s[0].marks = 85.5;

    s[1].roll = 102;
    s[1].marks = 91.0;

    printf("Student 1: %d %.2f\n", s[0].roll, s[0].marks);
    printf("Student 2: %d %.2f", s[1].roll, s[1].marks);

    return 0;
}

6. What is a Union?

A union is a user-defined data type similar to a structure, but all its members share the same memory location.

Syntax:

union Data
{
    int i;
    float f;
    char c;
};

7. Union Example

#include <stdio.h>

union Data
{
    int i;
    float f;
    char c;
};

int main()
{
    union Data data;

    data.i = 10;

    printf("Integer = %d", data.i);

    return 0;
}

Output:

Integer = 10

8. Structure vs Union

  • Structure: Each member has separate memory.
  • Union: All members share the same memory.
  • Structure: Multiple members can hold values at the same time.
  • Union: Generally, only one member's value should be used at a time.

9. Important Points

  • Structures can contain different data types.
  • The struct keyword is used to define a structure.
  • The dot . operator accesses structure members.
  • An array of structures can store multiple records.
  • Union members share the same memory location.

Quick Revision

struct Student
{
    int roll;
    float marks;
};

struct Student s1 = {101, 90.5};

printf("%d", s1.roll);

Here, s1 is a structure variable and s1.roll accesses its roll member.
