📦 Variables & Data Types

C Programming Notes

What is a Variable?

A variable is a named memory location used to store a value that can change during the execution of a program.

Variable Declaration

Before using a variable, we normally declare its data type and name. 


int age;
float percentage;
char grade;
double cgpa;

Variable Initialization

Initialization means assigning a value to a variable when it is declared. 


int age = 20;
float percentage = 89.50;
char grade = 'A';
double cgpa = 8.75;

Common Data Types

  • int – stores whole numbers.
  • float – stores decimal numbers.
  • char – stores a single character.
  • double – stores decimal values with higher precision.

Example Program


#include <stdio.h>

int main()
{
    int age = 20;
    float percentage = 89.50;
    char grade = 'A';
    double cgpa = 8.75;

    printf("Age = %d\n", age);
    printf("Percentage = %.2f\n", percentage);
    printf("Grade = %c\n", grade);
    printf("CGPA = %.2lf\n", cgpa);

    return 0;
}

Output


Age = 20
Percentage = 89.50
Grade = A
CGPA = 8.75

Important Points

  • Every variable should have a data type.
  • Variable names should follow C naming rules.
  • A variable can be assigned a new value during program execution.
  • Use single quotes for a character, such as 'A'.
